# 일본 자유여행 전문 3인 팀 역할 지침서

## 문서 목적

이 문서는 일본 자유여행 기획을 전문적으로 수행하는 3인 팀의 역할, 책임, 산출물, 협업 방식을 정의한다.  
팀은 다음 3개 역할로 구성된다.

1. **항공/숙소 예약자**
2. **식당/관광지 예약자**
3. **리뷰어**

각 팀원은 자신의 전문 영역에서 정보를 조사하고, 예약 가능성을 확인하며, 여행자의 예산·동선·취향에 맞는 최적안을 제안한다.

---

# 1. 항공/숙소 예약자

## 역할 정의

항공/숙소 예약자는 일본 자유여행의 이동과 체류 기반을 설계하는 담당자다.  
항공권, 공항 접근성, 숙소 위치, 숙박비, 교통 편의성, 체크인/체크아웃 조건을 종합적으로 검토해 여행 전체의 안정성과 효율성을 높인다.

## 핵심 목표

- 여행 일정에 맞는 최적 항공편 후보를 제안한다.
- 여행 지역과 동선에 적합한 숙소 후보를 선정한다.
- 예산, 위치, 교통, 후기, 취소 조건을 균형 있게 비교한다.
- 예약 전 반드시 주의사항과 리스크를 정리한다.

## 주요 책임

### 항공권 조사

- 출발지, 도착지, 여행 날짜, 인원, 수하물 조건을 확인한다.
- 직항/경유 여부, 출도착 시간, 항공사 신뢰도, 총 이동 시간을 비교한다.
- 저가 항공의 경우 위탁 수하물, 좌석 지정, 기내식, 변경/환불 규정을 별도로 확인한다.
- 공항 도착 후 시내 이동 편의성을 함께 검토한다.

### 숙소 조사

- 여행 목적에 맞는 숙박 지역을 추천한다.
  - 도쿄: 신주쿠, 시부야, 긴자, 우에노, 아사쿠사 등
  - 오사카: 난바, 우메다, 신사이바시, 덴노지 등
  - 교토: 교토역, 가와라마치, 기온 등
  - 후쿠오카: 하카타, 텐진, 나카스 등
  - 삿포로: 삿포로역, 오도리, 스스키노 등
- 역과의 거리, 공항 접근성, 주요 관광지 이동 시간, 주변 편의시설을 확인한다.
- 호텔, 료칸, 게스트하우스, 에어비앤비 등 숙소 유형별 장단점을 비교한다.
- 실제 후기에서 청결, 방 크기, 소음, 직원 응대, 위치 관련 내용을 중점 확인한다.

## 필수 확인 항목

- 항공권 총액: 운임 + 세금 + 수하물 + 좌석 지정비
- 숙소 총액: 숙박비 + 세금 + 숙박세 + 청소비 + 리조트피 여부
- 무료 취소 가능일
- 체크인/체크아웃 시간
- 늦은 체크인 가능 여부
- 조식 포함 여부
- 객실 크기와 침대 구성
- 엘리베이터 유무
- 흡연/금연 여부
- 역까지 실제 도보 시간

## 산출물 형식

항공/숙소 예약자는 다음 형식으로 결과를 제출한다.

```markdown
## 항공/숙소 제안

### 항공권 후보
| 후보 | 항공사 | 일정 | 가격 | 수하물 | 장점 | 단점 |
|---|---|---|---:|---|---|---|
| 1 |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |

### 숙소 후보
| 후보 | 숙소명 | 지역 | 1박 가격 | 역 거리 | 장점 | 단점 |
|---|---|---|---:|---|---|---|
| 1 |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |

### 최종 추천
- 추천 항공:
- 추천 숙소:
- 추천 이유:
- 예약 전 확인할 점:
```

## 판단 기준

좋은 항공/숙소 제안은 단순히 저렴한 선택지가 아니라, 전체 여행 동선과 피로도를 줄여주는 선택지다.  
특히 일본 자유여행에서는 숙소 위치가 식당, 관광지, 쇼핑, 야간 이동의 만족도에 큰 영향을 주므로 가격만으로 판단하지 않는다.

# 2. 식당/관광지 예약자

## 역할 정의

식당/관광지 예약자는 여행자의 취향과 일정에 맞춰 일본 현지에서 경험할 음식, 관광지, 체험, 입장권, 예약 필요 시설을 조사하고 예약 전략을 세우는 담당자다.

## 핵심 목표

- 여행 일정별 식당과 관광지 후보를 제안한다.
- 예약 필수 장소와 현장 방문 가능 장소를 구분한다.
- 동선에 맞춰 식사 시간과 관광 순서를 조정한다.
- 과도한 이동이나 대기 시간을 줄인다.

## 주요 책임

### 식당 조사

- 여행자의 음식 취향, 예산, 알레르기, 못 먹는 음식, 선호 분위기를 확인한다.
- 지역별 대표 음식과 현지 인기 식당을 조사한다.
- 예약 가능 여부, 영업시간, 휴무일, 라스트오더, 웨이팅 여부를 확인한다.
- 구글맵, 타베로그, 현지 예약 플랫폼, 공식 홈페이지 정보를 교차 확인한다.
- 관광지 근처의 무난한 대안 식당도 함께 준비한다.

### 관광지/체험 조사

- 여행 목적에 맞는 관광지, 쇼핑 지역, 체험 프로그램, 전망대, 박물관, 테마파크 등을 제안한다.
- 입장권 사전 예약 필요 여부를 확인한다.
- 운영시간, 휴무일, 혼잡 시간대, 이동 시간, 소요 시간을 정리한다.
- 계절성 요소를 반영한다.
  - 벚꽃
  - 단풍
  - 눈 축제
  - 불꽃놀이
  - 크리스마스 일루미네이션
  - 지역 축제

## 필수 확인 항목

- 예약 필요 여부
- 예약 가능 플랫폼
- 영업시간/운영시간
- 정기 휴무일
- 라스트오더
- 예산대
- 위치와 가장 가까운 역
- 숙소 또는 이전 일정에서의 이동 시간
- 현금만 받는지 여부
- 한국어/영어 메뉴 여부
- 어린이, 노약자, 채식, 알레르기 대응 가능 여부

## 산출물 형식

식당/관광지 예약자는 다음 형식으로 결과를 제출한다.

```markdown
## 식당/관광지 제안

### 일정별 후보
| 날짜 | 시간대 | 장소/식당 | 유형 | 예약 필요 | 예상 비용 | 이동 메모 |
|---|---|---|---|---|---:|---|
| Day 1 | 점심 |  | 식당 | 예/아니오 |  |  |
| Day 1 | 오후 |  | 관광지 | 예/아니오 |  |  |

### 예약 우선순위
1. 가장 먼저 예약할 곳:
2. 예약 난이도 높은 곳:
3. 현장 방문 가능한 곳:

### 대안 리스트
- 식당 대안:
- 관광지 대안:

### 주의사항
- 휴무일:
- 혼잡 시간:
- 이동 리스크:
```

## 판단 기준

좋은 식당/관광지 제안은 유명한 곳을 많이 넣는 것이 아니라, 실제 여행자가 무리 없이 방문할 수 있도록 동선과 시간, 예약 가능성까지 고려한 제안이다.

# 3. 리뷰어

## 역할 정의

리뷰어는 항공/숙소 예약자와 식당/관광지 예약자의 제안을 검토해 전체 일정의 완성도, 현실성, 리스크, 예산 적합성을 점검하는 담당자다.  
리뷰어는 최종 의사결정 전 여행 계획의 품질을 보증한다.

## 핵심 목표

- 일정이 실제로 가능한지 검토한다.
- 예산 초과, 이동 과다, 예약 누락, 휴무일 오류를 찾아낸다.
- 여행자의 취향과 제안 내용이 일치하는지 확인한다.
- 최종 예약 전 체크리스트를 제공한다.

## 주요 책임

### 일정 검토

- 하루 일정이 과도하게 빡빡하지 않은지 확인한다.
- 이동 시간이 실제보다 과소평가되지 않았는지 점검한다.
- 식사 시간, 휴식 시간, 쇼핑 시간, 체크인/체크아웃 시간을 반영한다.
- 비 오는 날, 지연, 웨이팅 등 변수에 대한 대안을 확인한다.

### 예약 검토

- 항공, 숙소, 식당, 관광지 예약 조건을 다시 확인한다.
- 취소/환불 조건과 예약 마감일을 점검한다.
- 예약자명, 인원, 날짜, 시간, 지점이 정확한지 확인한다.
- 예약 확정 메일 또는 바우처가 필요한 항목을 표시한다.

### 품질 검토

- 제안이 여행자의 목적에 맞는지 확인한다.
  - 맛집 중심
  - 쇼핑 중심
  - 가족 여행
  - 커플 여행
  - 부모님 동반
  - 혼자 여행
  - 저예산 여행
  - 프리미엄 여행
- 후기에서 반복적으로 나타나는 부정 이슈를 확인한다.
- 너무 관광객 위주이거나, 반대로 접근성이 지나치게 어려운 장소가 없는지 점검한다.

## 필수 확인 항목

- 날짜별 일정 충돌 여부
- 항공 도착/출발 시간과 첫날·마지막날 일정의 현실성
- 숙소 위치와 주요 일정 간 이동 시간
- 예약 필수 항목 누락 여부
- 휴무일/영업시간 오류
- 예산 초과 여부
- 현금 필요 여부
- 교통패스 필요 여부
- 여권명과 예약명 일치 여부
- 취소 가능 기한

## 산출물 형식

리뷰어는 다음 형식으로 결과를 제출한다.

```markdown
## 여행 계획 리뷰

### 종합 평가
- 전체 완성도:
- 가장 좋은 점:
- 가장 큰 리스크:

### 수정 필요 항목
| 중요도 | 항목 | 문제점 | 수정 제안 |
|---|---|---|---|
| 높음 |  |  |  |
| 중간 |  |  |  |
| 낮음 |  |  |  |

### 예약 전 최종 체크리스트
- [ ] 항공권 날짜/시간 확인
- [ ] 수하물 포함 여부 확인
- [ ] 숙소 무료 취소 기한 확인
- [ ] 식당 예약 날짜/시간 확인
- [ ] 관광지 입장권 필요 여부 확인
- [ ] 이동 시간 재확인
- [ ] 예산 총액 확인

### 최종 의견
- 진행 가능 여부:
- 조건부 진행 시 필요한 수정:
```

## 판단 기준

좋은 리뷰어는 단순히 오류를 찾는 사람이 아니라, 여행자가 실제로 편하고 만족스럽게 여행할 수 있도록 계획의 완성도를 높이는 사람이다.

# 팀 협업 프로세스

## 1단계: 여행 조건 수집

세 역할은 작업 전 다음 정보를 공유받아야 한다.

- 여행 국가/도시
- 여행 날짜
- 인원
- 출발지
- 예산
- 여행 목적
- 선호 여행 스타일
- 숙소 선호 지역 또는 조건
- 음식 취향과 제한사항
- 꼭 가고 싶은 장소
- 피하고 싶은 요소

## 2단계: 1차 제안

- 항공/숙소 예약자는 이동과 숙박 후보를 제안한다.
- 식당/관광지 예약자는 일정별 방문 후보와 예약 필요 항목을 제안한다.
- 두 제안자는 각자의 추천 이유와 리스크를 함께 적는다.

## 3단계: 리뷰

리뷰어는 두 제안을 통합해 다음을 점검한다.

- 일정 현실성
- 동선 효율성
- 예약 누락
- 예산 적합성
- 여행자 취향 반영도
- 리스크와 대안

## 4단계: 수정 및 확정

- 리뷰어의 수정 요청을 반영한다.
- 예약 우선순위를 정한다.
- 예약 완료 후 확정 정보를 최종 일정표에 반영한다.

# 공통 원칙

## 모든 역할이 지켜야 할 기준

- 최신 정보 확인을 우선한다.
- 공식 홈페이지 또는 신뢰 가능한 예약처를 우선 확인한다.
- 가격은 변동 가능성이 있으므로 확인 시점을 함께 기록한다.
- 여행자의 피로도와 동선을 가격보다 가볍게 보지 않는다.
- 예약 전에는 반드시 날짜, 시간, 인원, 취소 조건을 재확인한다.
- 불확실한 정보는 확정처럼 말하지 않는다.
- 대안 후보를 최소 1개 이상 제시한다.

## 추천 톤앤매너

- 실용적이고 구체적으로 작성한다.
- 장점뿐 아니라 단점과 리스크도 명확히 적는다.
- “좋아 보임”보다 “왜 적합한지”를 설명한다.
- 여행자가 바로 결정할 수 있도록 비교표를 활용한다.

# Skill로 만들지, MD로 만들지 판단

## 현재는 MD 파일이 적합한 경우

이 문서는 사람 또는 ChatGPT가 역할을 참고해 일본 자유여행을 기획하는 운영 지침서다.  
다음 목적이라면 MD 파일이 적합하다.

- 팀원별 역할을 명확히 정의하고 싶다.
- 여행 기획 담당자에게 업무 기준을 공유하고 싶다.
- Notion, Google Docs, GitHub, 사내 위키 등에 붙여넣어 관리하고 싶다.
- 아직 자동화보다는 역할 정리와 협업 기준이 중요하다.

## Skill로 만드는 것이 적합한 경우

다음처럼 ChatGPT가 매번 자동으로 같은 방식으로 작업하게 만들고 싶다면 Skill로 확장하는 것이 좋다.

- “일본 3박 4일 자유여행 짜줘”라고 입력하면 자동으로 3인 역할이 나뉘어 결과를 생성하게 하고 싶다.
- 항공/숙소, 식당/관광지, 리뷰어 관점의 산출물을 항상 같은 형식으로 받고 싶다.
- 여행 조건 입력 양식, 예약 체크리스트, 리뷰 기준을 재사용하고 싶다.
- 여러 도시와 여행 유형에 대해 반복적으로 동일한 프로세스를 실행하고 싶다.

## 추천 판단

현재 요청 기준으로는 **MD 파일로 먼저 운영**하는 것을 추천한다.  
이후 실제 여행 기획을 여러 번 해보면서 산출물 형식이 안정되면, 이 MD를 기반으로 **일본 자유여행 플래너 Skill**로 전환하는 것이 좋다.
